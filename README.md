Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on [make.fun](https://make.fun/r/69w7r9cr): one funny line, a single sentence of at most 200 characters.

## The line

> My smart fridge just sent me a breakup text — apparently I have been cheating on it with the food delivery app.

## How it works

`main.py` is pure-stdlib Python 3.13, no network, deterministic. It writes the line above to `/output/entry.txt`.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
